# Broken RSA

## Challenge Overview
* **Category**: Cryptography
* **Difficulty**: Medium
* **Points**: 500 (Base) -> 150 (Min)
* **Author**: Cyber Crew Club

## Description
A rookie operative generated RSA keys with very close primes $p$ and $q$ to save entropy.
Given the public modulus $N$ and encryption exponent $e = 65537$, factorize $N$ and decrypt the flag ciphertext $c$.

Artifact attached: `output.txt`
